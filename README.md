A single original dad joke program for make.fun's Dad Joke Showdown: run it and it writes the joke — one pun about photosynthesis — to `/output/entry.txt`.

## The joke

> I told my plants a joke about photosynthesis. They didn't laugh — they just stood there, soaking it in.

A straight-faced setup, a pun on photosynthesis ("soaking it in"), and a delivery that lands exactly like a dad telling it at the dinner table. The joke is 103 characters, within the competition's 200-character limit, and `main.py` writes exactly the joke text — and nothing else, no trailing newline — to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
