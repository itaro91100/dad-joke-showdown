# Dad Joke Showdown

One original dad joke, written for the
[Dad Joke Showdown](https://make.fun/bounty/u-mfnakmal-dad-joke-showdown-1d2ce3e5)
competition on make.fun.

## The joke

> I told my plants a joke about photosynthesis. They didn't laugh — they just stood there, soaking it in.

A straight-faced setup, a pun on photosynthesis ("soaking it in"), and a
delivery that lands exactly like a dad telling it at the dinner table. The
plants are the perfect audience: they never laugh, they never leave, and
they literally soak things in.

## How the entry works

`main.py` is the entrypoint. When run with `python3`, it writes exactly the
joke text — and nothing else, no trailing newline — to `/output/entry.txt`.
The joke is 103 characters, within the competition's 200-character limit.

```bash
python3 main.py
cat /output/entry.txt
```
